# Branch clearance report design

The actual requested column is the focal element; route ownership is explained
beside it, with measured counts anchored to the lower edge.

- Canvas1920x1080; background#101b1a, foreground#edf5ef, accent#a7e4cb;
  secondary text#b8c9c3, panel#1d302b. Dark neutral frames keep bright Minecraft
  footage readable. Accent is a dry label/proof colour, not a neon effect.
- Headings Montserrat900 (64px), numeric proof64–78px; body IBM Plex Mono400 (28–44px);
  metadata24px. Local font faces only, with licences.
- Main gameplay starts below the120px event header; footer leaves space for one
  short claim and speed/provenance. Footage retains its HUD, without covering it.
- Two-column comparison uses equal actual-source windows. No invented dramatic
  camera, glow, grain, gradient, bouncy entry or decorative background motion.
  The changing game image supplies depth; chart/proof scenes use plain panels.
- Motion: binary waterfall text entry,0.16–0.20s heavy/0.13–0.16s lighter,
  power4.out; calm scale pop0.5s/power3.out; hard scene cuts.
