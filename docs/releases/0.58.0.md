# 0.58.0 — sharper combat aim (no more orbit) + verified demo pipeline

## Aim: killed the WindMouse orbit (user 2026-07-24, reported twice)

The combat/bow aim used to slowly *circle* the target instead of landing on it — the classic
WindMouse orbit (accumulated velocity + wind carry the aim past the target and spiral in). Fixed:

- **Close-range direct settle** (< 7°): drop wind + momentum entirely and move a fixed fraction
  of the remaining angle straight at the target each frame → a crisp land, not a spiral.
- **Velocity damping** (0.72) on the far approach → no overshoot on long turns.
- Stronger base pull (gravity 6.5, maxStep 9, wind 0.30) and combat (gravity 5.5, wind 0.35,
  maxStep 10). Overshoot is now prevented by the close-settle zone, not by keeping gravity low.

Validated on the stand: moving-target fight — first damage 11.1s (deadline 25s), 12 damage dealt
(min 10), 0 freeze windows → **PASS** (no regression; the aim is faster AND still accurate).

## Demo/test tooling: verify-before-send

New mandatory rule (checklist): **verify footage with extracted frames + logs before claiming or
sending** — never ship an unwatched clip. `capture_demo.py` now records single-bot scenarios from a
fixed spectator camera (clean, no debug overlays), extracts frames, and sizes durations to the op.
Fixed a stand bug where arena-clean `/fill`s silently failed (dipped below the −64 world floor).

## How to test

- Combat aim: `;punkPlayer <name>` — the camera should snap onto the target and track it, no orbit.
- Bow: aim should converge crisply.
