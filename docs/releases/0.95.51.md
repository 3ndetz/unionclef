# 0.95.51 — out of holes, out of water

## Fixed

- **Drowning while digging up.** With a block over the head the bot always dug, even with air a
  few blocks away; under water and off the ground a block breaks 25 times slower. It now compares
  the dig (with those penalties) against a swim to the nearest breathable cell and takes the
  quicker. full56 drowned this way at minute 31.
- **Fleeing into water.** A flight's refuge can no longer be a cell with water at head height (the
  same full56 death started with a run from a creeper into a flooded cave).
- **The night shelter dug out its own cap** (0.95.49 moved the cap one block down, into the cells
  it digs): full54 dug and replaced it for eight minutes. Digging now happens only on the way down.
- **The outward food search forgot itself.** Its parent re-creates it, and each copy started the
  same heading afresh: full55, fifteen minutes on one unreachable leg. The search now outlives its
  task objects, counts patience only while it runs, and gives a stalled leg to the build engine
  (dig/pillar) before turning. A 1x1 shaft's foot no longer counts as "the surface".
- **A break followed by a different block in the same cell** (the shelter cap) is not a refused
  break any more, so it does not ban breaking there.
- **Smoker and blast furnace were always "in use"** (`!= null` on empty stacks), so a new one was
  never made; a new smoker is now priced in ticks by what is still missing.
