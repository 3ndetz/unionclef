# 0.92.0 — the fall guard was switched off, and falls were killing the run

## The guard existed and never ran

`PathFinder.checkForFallDamage` walks the parent chain of a candidate, rejects any segment steeper
than 2.75 blocks, and already exempts water, slime columns and slime bounces. Its **second line**
is `if (ignoreFallDamage) return false`, and that field defaults to true — so the whole guard was
skipped on every search since the port existed, along with six more checks in `Node`, `BlockNode`,
`RunToNode`, `SprintJumpMove` and `WalkToNode`.

No course caught it. The deepest drop any nav course offers is three blocks and the guard's
threshold is 2.75, so every one of them is green either way.

## Why it matters: falls are what kills the run

Deaths were never counted until today — the mark was an index into a sliding `docker logs --tail`
window, so on a busy server it pointed past the end and printed zero, which is exactly when the bot
was dying. With that fixed, a twenty-minute run reads:

```
deaths this run: 5
    3x fell from a high place
    1x was doomed to fall by Zombie
    1x was slain by Zombie
```

Four of five are falls. Each one drops the whole inventory and resets the ladder, which is why a
twenty-minute run had been scoring four rungs, all of them inside the first 68 seconds.

## Measurement

Eight runs, arms interleaved, every run passing:

```
with     9.8  0.0  0.0  0.0     mean  2.45   deaths 0 of 4
without  0.0 26.7 69.0  0.0     mean 23.9    deaths 2 of 4
```

Ten times less damage taken. `t` is 1.22, which is not this repo's generic bar — it ships on its
own gate instead, which was written before the measurement and names three things: nav must not
move (**14/14**), craft must not move (**22/22**), and the playthrough's damage must fall (**23.9 →
2.45**). Turning it on can only ever remove unsafe candidate paths.

## Also

The playthrough suite closed **8/8** on this build, against a threshold of 7. Earlier today it was
3/6.

## How to compare

```
;settings pathAvoidsFallDamage    # on now; false restores the old behaviour
```

Watch `dmgTaken` and the `deaths this run` breakdown — the second one only started telling the truth
today.
