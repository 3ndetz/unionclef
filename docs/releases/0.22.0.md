# unionclef 0.22.0 — "Alive": @wander + @mirror

New in-game commands so the agent acts like a live player instead of standing frozen in a lobby.

## @wander — idle-life movement
`@wander` makes the bot stroll/drift around the area in the background (bounded baritone wander,
increaseRange) so it never stands like a statue while chatting. Stop with `@idle` / `@stop`.

## @mirror — record + replay a player's movement
`@mirror <player> [rec|<sec>]` records a target player's movement trajectory (position over time,
inferring jumps from upward Y motion) and replays it: the bot reproduces their path + jumps from where
it stands (e.g. copy someone's parkour run). `@mirror play` replays the last recording. `@stop` cancels.
Note: a client only observes other players' POSITIONS (never their raw inputs), so this is a
position-faithful, jump-inferred mirror — the bot really walks/jumps the path, not a teleport.

These are TOOLS the agent invokes by its own judgment (no auto-daemon). Existing commands
(@gesture/@shift/@get/@give/@follow/@goto/@pursue/@scan/@place/@build/@sign…) are unchanged and now
documented for agents in mineswarm agent/shared/game_actions.md.
