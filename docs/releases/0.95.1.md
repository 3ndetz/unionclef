# 0.95.1 — the dig stands down for a miner that mines, not one that waits

A patch on 0.95.0, cut after the first long playthrough on it. Everything in 0.95.0's notes
still applies; this adds one fix, one bench pair, and four recorded gaps.

---

## The fix

0.95.0 made tungsten's route dig yield the camera while altoclef's block miner owns the aim
(the 00:12 stare). The miner's **back-off branch** — a target below the feet, the bot's own
floor in the way, sneak held, no swing — stamps the same claim, so the dig yielded to a miner
that was doing nothing: the 25-minute run stood 110 s over three cobblestone two blocks below
its feet (`execDigYieldMiner=1392`, `dbBlocked=1430/0/0`). The miner now makes a separate
**mining** claim only from the branch that is breaking a block, and the dig yields to that one
alone.

**HOW TO TEST:** `python deploy/runner/self_floor_dig_test.py` (a stone two below the feet
under a dirt floor, `@get cobblestone 1`): PASS is a cobblestone within seconds, on this build
3.2 s. `python deploy/runner/two_driver_mine_test.py` (the 00:12 scene, executor and miner on
adjacent blocks): both blocks gone, `breakMissWhy` transit 0.

## The bench

`gamer_smoke.py`'s fresh start now kills last run's item drops around the body where it
landed. The old `kill @e[type=item,distance=..40]` measured from the console and ran before
the start was chosen, so a wooden pickaxe dropped underground by an earlier run held the
25-minute run for its first seven minutes.

## Recorded, not started (the 25-minute run on 0.95.0)

- **G93** a pickaxe drop ten blocks underground was pursued for seven minutes with spruce
  across the lake in the frame — the catalogue's pickup-first rule needs a cost.
- **G94** a step down onto a snow layer is a hop the physics engine gives up on (32898 tests).
- **G95** the night job was a block 86 below: a 90-block shaft into a trial chamber, a Breeze,
  a respawn at world spawn with nothing.
- **G96** after the respawn, a reach route armed for a block one cell away with the navigator
  not running, and a shimmy every minute.

Ladder on that run: wood tools 461 s, stone tools 616 s, no iron in 25 minutes, two deaths.
The morning run on the same build reached iron tools at 411 s from a spawn without those
walls; the difference between the two is the list above.
