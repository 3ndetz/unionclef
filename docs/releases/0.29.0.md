# 0.29.0

Combat follow-up to 0.28.0 plus a new flee lever.

## Self-inflicted void falls are gone

0.28.0 stopped most of the bot walking off the island, but a residual ~1–3 falls
a run remained. Telemetry traced them to the **approach phase**: after a kill the
bot re-closes on the respawned target through the pathfinder *executor*, which
sprint-jumps and had no void clamp (only the combat aura did). The shared
`VoidGuard` now runs after the executor tick during punk (and flee) too, so the
same "no sprint/jump toward a rim, plant with sneak" rule applies while pathing.

Result on the 5×5 void-island bridge arena, bot vs a stationary target, three
back-to-back 80 s runs: **0 falls every time** (kills 1 / 7 / 6, min Y never left
the island). The self-inflicted fall — the thing that was happening "constantly"
— is fixed.

Mutual fights (both bots hunting each other) still trade the occasional
knockback-fall: an opponent that catches you at the rim can launch you off in the
air, which no ground clamp can undo. That's ordinary PvP and it's symmetric
against an identical bot; keeping the void at your back (positioning) is the next
step there.

## New: `runAwayPlayer` — flee, keeping distance

The mirror of `punk`. Instead of pathing toward a target, tungsten paths to the
safest reachable point **away** from it and re-plans as it chases — void-aware,
so a flee waypoint is only an interior cell (never the rim), and the shared
`VoidGuard` clamps the executor so fleeing can't carry the bot into the void
either. Samples angled fallbacks so a wall or a gap doesn't trap it.

- `;runAwayPlayer <name> [distance]`
- py4j / MCP: `runAwayPlayer(name, distance)`, `runAwayStop()`, `runAwayStatus()`
- Mutually exclusive with `punk`. The agent decides when to run; the mod keeps
  the distance.

Tested (`deploy/runner/runaway_test.py`): a chasing attacker, the bot fleeing on a
15×15 void island — it keeps ~8 blocks average and doesn't back off into the void
by its own movement. It can still be caught and knocked off if the attacker runs
it down at equal speed on a bounded island.

## How to test

```
;punk <player>                 # hunt
;runAwayPlayer <player> 8       # flee, keep 8 blocks
```
`deploy/runner/bedwars_combat_test.py [secs] [solo|mutual] [flat|bridge]` — combat
falls/kills. `deploy/runner/runaway_test.py [secs]` — flee.
