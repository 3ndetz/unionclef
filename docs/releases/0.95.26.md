# 0.95.26 — free-form movement never steps into lava (flee + combat lava clamp)

Follow-up to 0.95.25. The A* pathfinder already treats lava as a wall, so PLANNED walks avoid it. The
gap was the NON-planned, free-form movement layers, which had a void guard but no lava guard.

## What it fixes

- `VoidDetector.lavaAhead` / `isLavaAt`: the lava twin of `edgeAhead` -- samples the movement direction
  for a step whose feet cell (or the one below) is lava.
- `RunAwayTask.safeFleePoint`: a flee candidate whose ground is lava, or whose straight run to it crosses
  lava, is skipped (a nearer / other direction is tried; if all are lava the flee holds rather than
  stepping in). Before this it checked void-safety only.
- `RunAwayTask.driveAwayRaw`: the key-driving flee fallback (deliberately has no ground probe for the
  void, which VoidGuard clamps after) now releases the keys if the away heading leads into lava within
  a step and a half.
- `VoidGuard.protect`: the final word on the keys for free-form combat/flee movement gets the same clamp
  as the void: if the pressed keys or the velocity head into lava within the stopping lookahead, cut
  jump/sprint and release the movement keys. It runs under `!movementOwnsTick`, so it never touches a
  pathfinder bridge across lava.

All of it is a NO-OP wherever there is no lava next to the bot's free-form movement, which is why it
cannot regress the standard courses.

## Scope -- honest

This closes the "bot walks/strafes/flees into lava under its own keys" class. It did NOT, on its own,
stop the nether-stage death seen from `nether-fresh`: the bot still died "tried to swim in lava" while
hunting Endermen over the nether's lava. Three free-form-movement clamps not preventing it is strong
evidence that entry is not the bot's own key-driven movement -- most likely Enderman KNOCKBACK into lava
(Endermen hit hard, and the nether stage fights them over lava), or a combat-approach gap. That is the
next focused pass (a proper death-tick instrument: hurtTime / onGround / velocity / feet-lava at the
moment of entry, then knockback-aware positioning near lava).

## Validation

- Nav baselines `nav_flat` / `nav_staircase` / `nav_descend`: **3/3 PASS** (~29-30 fps, 0 freezes,
  0 self-falls, 0 invalid runs) on the built jar -- the tungsten changes run clean and are a no-op there.
- Underground flood (OBS flat bench) unaffected (no lava beside the bot's free-form movement after the
  lake converts).
- Nether stage (`--from nether-fresh`): the bot hunts Endermen for pearls (4/14 earlier), then still dies
  to lava as above -- the remaining, separately-scoped frontier.
