# 0.47.0

Combat rework, pillars 2-3: **aim smoothing** (anti-shake) and **bunny-hop**. Please test
live — the shake is a live-only symptom I can't reproduce on the stand.

## Aim smoothing (anti-shake)

The aim shook violently against a live player because the enemy moves via position packets
(noisy velocity / lead) and the best-aim-point flips, so the camera chased a jittery target
and never settled inside the trigger's 40° window → no hits.

Fix: the aim target is now low-passed — it snaps on a big jump (first aim / target switch /
teleport) but otherwise blends halfway toward the raw aim each tick. That kills the
high-frequency jitter while still tracking a moving target, so the angle window holds and the
trigger fires. Stand: no regression (pvp_moving first hit 6.7s vs 15.5s before, 18 dmg;
pvp standing 20 dmg; 0 freezes).

## Bunny-hop / always-moving

Combat now jumps on a fast cadence (~0.3–0.6 s, was 0.65–1.35 s) so the bot bunny-hops and
jukes around the target instead of standing and clicking — crits + a harder-to-hit profile.
Still void-guarded (never jumps toward a drop).
