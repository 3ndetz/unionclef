# 0.51.0 — break primitive (mineBlocks / mineStatus)

A first-class BREAK primitive for the cognitive agent, mirroring the place/fill
primitives. Mine an arbitrary set of blocks (in reach) through the same tungsten
executor break-queue that `@goto` uses when it clears a planned wall — so tool
equip, gravity re-mine, and BreakRules protection all apply. No physics leg: the
bot stands still and mines, so it composes cleanly with a preceding `gotoXYZ`.

## What's new

- **py4j `mineBlocks(positions)`** — `positions` = list of `[x,y,z]`. Queues the
  blocks into the executor's break queue and starts draining them. Out-of-reach
  blocks stay queued (reposition with `gotoXYZ`, then poll). Returns
  `{ok, queued}` or `{ok:false, reason}`.
- **py4j `mineStatus()`** — `{mining, remaining}`; `mining=false && remaining=0`
  means the queue is drained.
- **MCP `mineBlock(x,y,z)` / `mineStatus`** — single-block convenience wrapper +
  poll, registered for the MCP surface.

This is the missing half of the worldedit toolset: with `set`/`walls`/`hollow`/
`cyl`/`sphere` selections (place) plus `mineBlocks` (break), an agent can compose
`//replace`-style ops (break-then-place) entirely from primitives.

## How to test

Stand test `deploy/runner/diag_mine.py`: builds a 3-block dirt wall in reach,
calls `mineBlocks`, polls `mineStatus`, verifies the blocks are air. Regression
guard: `deploy/runner/break_test.py` (executor mining path) must stay 4/4.
