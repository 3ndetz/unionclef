# A source out of reach is given up

A 30-minute run on 0.95.64 stood fourteen minutes on "Getting within 3 blocks" of one lava source,
and the next run stood at the same source from minute sixteen to the end. No cell near it was
safe to stand on, so the approach never closed in. The chooser above it gave the source up every
three minutes and then, with nothing else on offer, lifted its own ban and handed the same source
back.

`CollectBucketLiquidTask` now gives a source up when the approach has not gained half a block in
20 seconds, and takes the next one; the blacklist goes through the source filter, so it holds.
The clock pauses while the task is interrupted (Unstuck Chain broke in every 25 s in that stall,
and a clock that restarted with the task never ran out).

Also: when the iron pickaxe wears out with cobblestone in the pack, the bot crafts a stone
pickaxe instead of looking for wood for a wooden one. The stone-pickaxe step required a pickaxe
to exist first, for mining the cobblestone it was already carrying; from the stall checkpoint the
old build spent five minutes underground on "wooden_pickaxe".

Measured:

- new course `lava_boxed_source` (the nearest source sealed in bedrock, an open one 18 blocks
  on): 0.95.64 0/2 (no bucket in 150 s), this build 2/2 at ~34 s, "No closer to the liquid ...
  trying another source" once per run.
- from the stall checkpoint (`repro-lava-stuck-cell`): stone pickaxe crafted in the first minute,
  lava collected, portal lit and the nether reached at ~4.8 minutes; 0 deaths.
- regression: craft 26/26 and `nav_flat`, `nav_staircase`, `nav_water`, `nav_water_pillar`,
  `nav_bridge` PASS at 29-30 FPS; a 30-minute native run from `full59-before-portal` PASS, 0
  deaths, median 27 FPS. That run took another road (iron, then ten minutes after food and two
  nights underground) and did not reach the portal, so it says nothing about the lava either way.

**Known (added after release):** a second run from `repro-lava-stuck-cell` on the published jar
died in the portal-site lava at 3.2 minutes: the obsidian cast failed, a wander took the bot into
the pool, and the escape route's second waypoint was a block up -- the walker jumps only from the
ground, so floating in lava it walked into the shore face and burned 0.9 blocks out. One death in
two runs from that checkpoint; the fix is the next release.

The give-up never fired in the stall-checkpoint run (the lava there was taken without
it), so in the field it is measured by the course only. The whole playthrough is still open.
