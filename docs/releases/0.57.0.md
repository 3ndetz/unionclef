# 0.57.0 — @@undo + faster WindMouse aim

## @@undo (WorldEdit undo)

`@@undo` restores the last modifying WorldEdit op. A snapshot of the selection's blocks is
taken automatically before `@@set` / `@@replace` / `@@walls` / `@@hollow` / `@@cyl` /
`@@sphere`; `@@undo` breaks the region and rebuilds the snapshot (reuses the break queue +
`buildBlocks`), poll `@@undostat`. Up to 10 levels. py4j `undoLast`/`undoStatus` + MCP.

Validated: `worldedit_cmd_test` — `@@set stone` (3/3) → `@@undo` → all air again. PASS.

## Faster WindMouse aim (no slow orbit)

The aim was slowly circling the target (user, live). The orbit is the WindMouse *wind*
component + a too-weak gravity pull. Fixed by cutting wind and raising gravity (a stronger,
more direct pull) — WITHOUT over-raising the step (which would overshoot):

- default: gravity 3.5 → 5.0, wind 1.2 → 0.8, maxStep 5.0 → 7.0
- combat: `combatWindMouseGravity` 3.2 → 4.3 (×2 in CombatController → 8.6, was 6.4)

Still pixel-quantized through the vanilla mouse pipeline (humanized, anti-cheat-safe). An
aggressive first cut over-boosted into overshoot (pvp_moving 20→14 dmg); this moderated tune
lands hits again (pvp_moving 16 dmg, first hit 8.9s, 0 freeze — PASS).
