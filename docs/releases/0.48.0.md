# 0.48.0

More combat anti-shake: the enemy velocity is now smoothed at the source.

## Enemy-velocity smoothing (root anti-shake)

0.47 low-passed the aim angle; this smooths the input that feeds it. The lead prediction
used the raw per-tick position delta, which spikes and zeroes for a packet-moving human
(irregular position packets) — the underlying cause of the jitter. It's now an EMA
(0.6 old + 0.4 new), so the predicted position and the aim stay stable while still
tracking a moving target.

Stand: pvp_moving 20 dmg, pvp standing 18 dmg, 0 freezes — no regression. The shake itself
is live-only; please test live and say if it's still shaking.
