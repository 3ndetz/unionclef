# 0.95.41 — you can see the route now; baritone's answers ported where ours were wrong

Everything since 0.95.37. Most of it came from recorded playthroughs and checkpoint resumes, not
from reruns of old courses.

## Visible

- **Route overlay for the drivers the playthrough actually uses.** The walker's route (cyan, with
  the next waypoint and the end box), the ported baritone movement queue (blue, blocks to break in
  red, blocks to place in green), the block being mined (orange, with a box that grows with
  progress) and the dig target (yellow). Before this only FastNavigator and the physics replay drew
  anything, and the bench switched every overlay off for the whole run, recorded runs included.
  Lines are 3 px now instead of 1.

## Fixed (each one reproduced first, most of them ported from baritone)

- **A break the server rejected was mined forever.** Vanilla 1.21.11 keeps breaking whenever
  `currentBreakingPos` matches, without sending a new START; after one rejection every STOP met a
  server with nothing to stop. One START, sixteen client-side "completions", the stone never gone.
  Now the controller starts over properly, as baritone's `BlockBreakHelper` does. nav_cliff 1/3 → 3/3.
- **Arriving in mid-air.** The goal task counted the feet passing over the goal during a sprint jump,
  released the keys in the air and coasted three blocks past it. It now arrives only when something
  holds the body (baritone's AT_GOAL comes after the path finishes). nav_powder_pit passes for the
  first time.
- **Powder snow** is an obstacle to break and never a floor (baritone `canWalkThroughBlockState`),
  not a lethal hazard. Freeze damage no longer counts as being attacked, and the escape breaks the
  snow the body is actually in. Planner corners and parkour gaps follow the executors' lethal-column
  rule, so the walker is no longer handed routes it then refuses.
- **Fleeing took the navigator hostage.** MobDefense only started its safety search when the
  navigator was idle, so an interrupted task's route kept replanning to a cell 70 blocks down while
  the bot stood still at 4.5 hearts for ten minutes. Fleeing now takes the navigator over and
  searches with a GoalRunAway-style heuristic, so a partial route still moves the body away.
- No sprint when overshooting would land in danger. Never break a block that holds lava back. The
  floor on soul sand is the soul sand. No unarmed night run back to the gear you just died next to.
  The wander target follows the ground (a 20-minute stall on the spawn mountain).

## Bench

- Checkpoints by default: every 5 minutes (last 4 kept) and `rung-<rung>` at every ladder rung.
  `--raw-resume` resumes a checkpoint as it was frozen: no day, no clearing, no healing.
- gamer_smoke counts every vanilla death message (lava deaths used to read as zero).
- The freeze clock counts break progress as activity, so a 7.5 s hand dig is a dig, not a freeze.
- New courses: nav_powder, nav_powder_pit, mob_unarmed.
- py4j: `getGameState` reports food, saturation, breakingProgress and msSinceBreakProgress;
  `getCurrentGoal` reports the tungsten target; `breakResetStats` / `breakEvents` trace breaks.
