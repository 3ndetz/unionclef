# 0.54.0 — //replace worldedit op (break-then-place)

Completes the worldedit toolset: with `set`/`walls`/`hollow`/`cyl`/`sphere` (place) and
`mineBlocks` (break, v0.51), an agent can now `//replace` — swap one block for another
across a selection — composed from the primitives, in real survival.

## What's new

- **py4j `replaceSelection(from, to)`** — swap every selection cell whose block is `from`
  (or `"*"`/`"any"` = any non-air) for `to`. Two phases: it BREAKS the matching cells via
  the tungsten executor break queue (the same drift-immune path as `mineBlocks` — tool
  equip, protection, gravity re-mine all apply), then places `to`.
- **py4j `replaceStatus()`** — poll: phase `breaking` → `placing` → `done`, with
  `placed`/`remaining` counts. Reposition (`gotoXYZ`) if `remaining` stalls out of reach.
- **MCP `replaceSelection` / `replaceStatus`** — registered.

Real survival placement (`placeBlockAtRaw`, bottom-up so each cell has support), not a
server fill — works in survival and respects place/break protection rules.

## How to test

`deploy/runner/diag_replace.py`: a 3-cell stone column, `replaceSelection(stone,
cobblestone)`, poll to done, verify the cells are cobblestone. Regression:
`break_test.py` stays 4/4.
