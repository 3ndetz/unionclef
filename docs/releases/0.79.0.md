## A grave permanently taught the pathfinder not to break cobblestone slabs

`ConstructGraveTask` protects a few block types from the pathfinder while it builds, and releases
them afterwards. The two lists were written by hand and had drifted:

| protected | released |
|---|---|
| `COBBLESTONE` | `COBBLESTONE` |
| `OAK_SIGN` | `OAK_SIGN` |
| **`COBBLESTONE_SLAB`** | `SMOOTH_STONE_SLAB` |
| `SMOOTH_STONE_SLAB` | **`STONE_SLAB`** |

So the slab it actually added was never released — the pathfinder refused to break cobblestone slabs
for the rest of the session — and the one it released had never been added. There is now **one** list,
used by both calls, because two hand-written lists that must stay in step do not.

Found by encapsulating the thing rather than by looking for it, which is the argument for the rest of
this release.

## G-0b: altoclef stops reaching into the pathfinder's object model for its own policy

Four collections were altoclef's own data, stored in and mutated through `baritone.api.Settings`:

| | sites | now |
|---|---|---|
| `acceptableThrowawayItems` | 7 | `AltoClef.getThrowawayItems()` |
| `blocksToAvoidBreaking` | 11 | `avoidBreaking` / `allowBreaking` |
| `blocksToAvoid` | 3 | `avoidWalkingThrough` / `allowWalkingThrough` |
| `avoidUpdatingFallingBlocks` | 2 | `setAvoidUpdatingFallingBlocks` |

The throwaway list is a genuine data move — it is derived from altoclef's own settings, pushed into
the pathfinder so it can plan placements, and then read back out of it by six callers. It is now
snapshotted as the **union** of the shipped defaults and ours, taken at the one moment both halves are
present; reading only the altoclef half would have quietly narrowed what the bot is willing to place.

The other three are all **writes** — nothing ever read them back — so that part is encapsulation
rather than a data move, which is the honest description of it. One seam instead of sixteen, and when
the pathfinder behind it is replaced only five methods change.

`getClientBaritoneSettings()` call sites: **46 → 38**. What remains is configuration altoclef writes
once at init to tune the pathfinder — `allowParkour`, `blockPlacementPenalty`, `movementTimeoutTicks`
and friends. That is not altoclef's data and there is nowhere to move it to until shredder goes; it
leaves when shredder does.

**Not** a count-shaving exercise: imports of `baritone.*` are unchanged at 14, and the goal API alone
is used fully qualified at about ten more sites the count has never seen.
