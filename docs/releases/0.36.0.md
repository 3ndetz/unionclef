# 0.36.0

Same code as 0.35.0 — re-released to fix the GitHub release ordering, and rolls up
everything since the mis-tagged 0.32.

## Why 0.36.0 (release-ordering fix)

Releases 0.32–0.35 were published onto **pre-existing draft tags dated 2026-04-03**
(left over on those version numbers from the 1.21.1 line). GitHub sorts the releases
list by `created_at`, so those releases sorted *below* the July 0.28–0.31 ones — the
latest work looked older than 0.31. 0.36.0 is a fresh tag (no stale draft), so it
lands at the top with the correct date. (Root cause also fixed in `AGENTS.md`: always
`gradlew :1.21.11:githubRelease` and verify the jar.)

## What's in it (cumulative, since 0.31)

- **Ranged bow aim on TrajectorySolver** (0.33) — vanilla-physics ballistics + self-
  tracked lead; standing 5/5 at 24 blocks.
- **Dynamic combat movement** (0.34) — circle-strafe / kite / crit-jumps / flank on
  occlusion; was static stand-and-hit (pvp_test: 136 blocks moved, kill, 0 freezes).
- **Crash fix #26** (0.34) — `PathExecutor.getCurrentNode` empty-path guard (was an
  IndexOutOfBounds that crashed the client on a mining-goto).
- **Unreachable-goal give-up #27** (0.35) — net-progress-based; no more infinite
  pathfind spin on goals we can't reach yet.
- Experimental `smartMoves` block-space rework stays behind its flag (off by default).

## Known / in progress
