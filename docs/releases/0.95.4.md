# 0.95.4 — the bread deadlock is out; a crafting table is four planks, not a fight

A patch on 0.95.3, cut after the third sixty-minute playthrough spent forty-six of its minutes
in a single loop and reached no iron. That loop is gone.

---

## The fix (G103)

The third run reached food in four minutes and then never advanced: it wanted bread, had no
crafting-table item, saw a placed table "on the way", and returned "Picking up the crafting
table while we are at it" every tick — which **preempts** the flow that would just craft a fresh
table. On the survival world the break false-fails ("Block … failed to break! Maybe private
area", `WorldSurvivalChain`'s half-second verdict), so the reclaim never obtained the table,
never crafted the bread, and cycled with "Blacklisting extra crafting table" 971 times. The bot
had four spruce logs the whole time.

0.94's G80 already ruled a crafting table is worth four planks, not a climb or a dig; the same
holds for a dig into a table that will not break. The reclaim now **skips when the pack can make
a table now** (four planks, or a log), and the reclaim flag is dropped so it stops re-arming —
`DoStuffInContainerTask` crafts a fresh table and proceeds. The deadlock cannot form because
obtaining a table no longer depends on a break that fails.

**HOW IT WAS VERIFIED — from the checkpoint, not a fresh hour.** This is the first fix developed
against a world checkpoint (`deploy/runner/checkpoint.py`, added in 0.95.3's cycle). Resuming the
`loop-bread` checkpoint: before, "Blacklisting extra crafting table" ran 971 times over the loop;
after, two five-minute resumes read **zero** of them, and the bot forages food and gathers iron
with its item count climbing 63 → 104 instead of looping. The shield-craft bench
(`shield_craft_test.py`, the pure craft-grid carousel) still passes in ten seconds.

**HOW TO TEST:** `python deploy/runner/checkpoint.py restore loop-bread` then `@gamer`, or
`python deploy/runner/gamer_smoke.py 6 --from loop-bread` — the bot leaves the crafting table and
gathers, instead of the bread/table churn.

## Known, not fixed

- **G104**: a fresh opening can still spend several minutes on a stone-sword craft that waits on

  the bread loop (this shows 8 "Blacklisting extra", not 971) and not caused by this fix — the
  craft-grid family already tracked as the shield carousel. Checkpoint `run4-end` sits near it.
