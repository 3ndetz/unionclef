# unionclef 0.23.0 — `@alive`: agent-orchestrated "act like a player"

`@wander` (0.22.x) was a dumb fidget burst. 0.23.0 turns it into `@alive` — a background behavior the
AGENT drives with LIVE, changeable GOALS, that REPORTS EVENTS back. The agent sets the config, keeps
talking/playing, and reacts to (or preempts with a real task) the events. The task is a mechanical
mod-side executor; the thinking (what to target, when to preempt) stays in the LLM.

## `@alive <mode> <nicks> [sec]`
- `@alive idle` — fidget on the spot (look around, glance at people, hops). `@wander` = this.
- `@alive watch <nick1,nick2>` — keep LOOKING at the configured nicks (turn to whoever's present).
- `@alive near <nick>` — drift toward + hang around a nick, fidget next to them.
- `@alive roam` — wander random nearby points within a bounded area, looking around.
- `@alive` (no args) — emit the current config as an event.
All input-driven (no pathfinding / no block-break) so it works in lobbies AND private zones and won't
walk off an edge. Re-issuing `@alive` with new args updates the config WITHOUT restarting the task
(`AliveConfig` is read every tick; `AliveTask.isEqual` keeps the running task alive).

## Events (mod -> stdout `ALIVE_EVENT {json}` -> latest.log -> agent's events.sh `[alive] …`)
- `target_lost <nick>` — a watched/near person left render.
- `stuck <targets>` — no movement progress while trying to move (re-enter / switch engine).
- `arrived <nick>` — reached a near-target.
- `config` / `status` — current config echoed.

## Files
`tasks/movement/AliveConfig.java` (live config), `tasks/movement/AliveTask.java` (rewrite: 4 modes +
event emission), `commands/AliveCommand.java`, `commands/WanderCommand.java` (now `@alive idle`),
registered in `AltoClefCommands`. Agent side (mineswarm): the `alive` source in
`agent/scripts/_events_lib.py`, docs in `agent/shared/game_actions.md`.

Note: alive events reach the agent through its per-turn `events.sh` while it's active. Waking a
sleeping agent from an alive event is not wired (alive only runs during active play).
