# 0.30.1

Follow-up to 0.30.0 — an anti-permanent-stuck safety net for tungsten-primary
navigation.

## Never freeze forever

0.30.0 made the bot cross terrain via the drift-immune walker. This adds the
backstop: while tungsten is driving a goal, if the bot hasn't moved for 5 s the
nav is treated as trapped (an unreachable sub-goal, or a stale-rooted re-plan
loop where the search keeps rejecting its own path because the root drifted from
the player). It resets the tungsten nav so it re-plans from where the bot
actually is, and after a few fruitless resets yields to the wander so the bot
walks out of a local trap instead of standing still.

Verified: on the survival mountain (peaceful) the bot traversed ~100 blocks,
descended ~34, found a dark-oak tree and chopped it — moving continuously, no
permanent stall. `swap_test` still PASS (the net never fires during normal fast
navigation — the bot reaches its goal first).

## Known / in progress

- Parkour (jump-gaps, 2-block walls) still uses the physics executor and can
  struggle — normal walking/climbing terrain is what's fixed.
- Full-game soak against mobs (survival difficulty) needs food/combat/shelter
  progression — separate from navigation.
