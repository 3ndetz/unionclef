# 0.56.0 — @@ WorldEdit command handler + scaffolding cleanup

Two operator-facing features toward the tungsten WorldEdit toolset (user 2026-07-24).

## @@ WorldEdit commands

Typed WorldEdit-like commands, prefixed **`@@`** to distance them from the main `@`
altoclef commands (and dodge the `@set` clash) — mirrors WorldEdit's `//`:

- `@@pos1` / `@@pos2` — selection corners at the player's block
- `@@hpos1` / `@@hpos2` — corners at the looked-at (crosshair) block
- `@@sel` — clear selection · `@@size` — min/max/size/volume
- `@@set <block>` · `@@replace <from> <to>`
- `@@walls` / `@@hollow` / `@@cyl` / `@@sphere <block>`
- `@@copy` / `@@paste` — clipboard (snapshot the selection, re-anchor at the player)
- `@@cleanup` — mine out nav scaffolding (below)
- `@@restat` / `@@minestat` — poll replace / mine progress
- `@@schem load <name>` — parse the file agent-side and drive `buildBlocks` (stub note)

Thin wrappers over the existing py4j primitives (`select` / `fillSelection` / `replace` /
`buildBlocks` / …). The `@@` chat is intercepted in `SendChatEvent`, reading the player /
crosshair block on the client thread, then running the handler off-thread (the primitives'
`onClientThread` marshalling would deadlock the client if called on it). Real survival
placement — protection rules apply. All primitives also on py4j (`we(cmd)`, `copySelection`,
`pasteClipboard`, `selectionSize`) and MCP.

## Scaffolding cleanup

Building UP makes tungsten place pillar / bridge blocks under itself (garbage around the
build). `ScaffoldRegistry` records those, and `cleanupScaffold` (py4j / MCP / `@@cleanup`)
mines them back out TOP-DOWN via the break queue. It's a **finite set mined once each with
no re-placing during cleanup — it cannot loop** (the user's explicit requirement).

## Validated

- `worldedit_cmd_test`: `@@pos1/@@pos2` → selection, `@@set stone` (3/3), `@@replace stone
  cobblestone` (3/3), `@@copy`+`@@paste` re-anchored. PASS.
- `diag_scaffold`: pillar up → `cleanupScaffold` mines all 6 blocks, registry cleared, **no
  loop** (not timed out). PASS.
- Regressions: `worldedit_shapes_test` 3/3, `break_test` 4/4.
