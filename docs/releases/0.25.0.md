# 0.25.0

## Features

- **Combat rework — the bot actually fights now.** The trigger no longer
  depends on vanilla's crosshair pick (an OUTLINE raycast that tall grass
  blocks — the old "freezes staring at you from the grass" bug). It decides
  with its own checks (reach to hitbox, COLLIDER line of sight, look angle,
  attack cooldown) and delivers via `attackEntity` directly. Removed the
  ESCAPE-every-cooldown-cycle rule that made the bot sprint away after each
  hit, enabled combat movement by default, added a direct charge for the last
  half-block (it used to hover at 3.06 with a 3.0 reach), falling-crit window,
  knockback-danger threshold 2→4, combat BFS 2000→800 nodes (main-thread
  hitching). Autotest: first damage in 4.3s across a grass field, victim
  killed, zero freezes — fight inside tall grass.

- **Tungsten mines through walls.** `;goto` plans breaking when a breakable
  wall blocks an adjacent cell: cost from vanilla mining ticks
  (`calcBlockBreakingDelta`), gravity-block surcharge, physics guidance stops
  at the wall, the executor aims and holds the attack key (vanilla drives the
  mining), fallen sand gets re-mined, the goto retry runs the next leg through
  the opened passage. Settings: `allowBreak` (default true),
  `breakCostMultiplier`. Autotest: sealed bedrock boxes with dirt doors —
  plain wall and sand-above-door both pass.
  Limits (v1): horizontal break-through only, no placing, block-space A*
  doesn't accumulate path cost so open-terrain detours still win over mining.

## Fixes

- Path streaming: stale-rooted emissions rejected (root >2 blocks from the
  player caused instant "drift 8.9" aborts), bestSoFar reset on search
  re-root, re-search budget 220ms→3s.
- `;goto` after `;stop` no longer silently ignored (stale stop flag).

## How to test

PVP: `;punkPlayer <name>` — expect a committed fight, works in tall grass.
Mining: wall a corridor with dirt, `;goto` past it — the bot mines through
(`deploy/runner/break_test.py` has the exact course geometry). Full stand:
`sh deploy/autotest.sh` on a docker host with the mineswarm-mc image.

## Known quirks

- Persisted `config/tungsten.json` overrides new defaults — set
  `;settings combatMovementsEnabled true` on installs that predate 0.25.0.
- Squeezing through a 1-wide mined hole can trip the replay drift guard;
  raise `;settings driftThreshold 1.5` for mining-heavy routes.
