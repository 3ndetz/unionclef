# 0.95.14 — nether portal: flood-gather + build + light, end to end (G108)

The obsidian nether-portal path (`@build portalobs`, used by `@gamer` after iron) now gathers
obsidian by flooding a lava lake, builds the full 4x5 cornered frame, and lights the portal — the
standing post-iron ceiling. Four root-cause fixes:

- **Flood-gather reclaim** scoops the actual water SOURCE blocks in the pool region until the sheet
  drains, so the fresh obsidian is exposed and mined (previously it scooped one fixed cell that could
  be flowing water, never finished, and re-flooded forever).
- **Tungsten pillars/bridges with the cheapest hotbar scaffold (cobblestone), never a valuable
  full-cube like obsidian** — the placer used to tower a build up out of its own material.
- **Top row built from a temporary front scaffold**, not a mid-air pillar: a cobblestone standing
  wall is raised one row in front of the frame so the top row places from a stable side stand, then
  mined back out before lighting. This removes the top-row hard-stall.
- **Trustworthy portal bench**: `deploy/runner/nether_portal_test.py` matches the block registry id
  (locale-independent) and retries the scan, and gathers a small obsidian reserve.

## How to test

```
OBS=1 python3 deploy/runner/nether_portal_test.py        # full flood -> gather -> build -> light
OBS=1 GIVE_OBS=1 python3 deploy/runner/nether_portal_test.py   # isolate the frame build
```

PASS = a real `minecraft:nether_portal` block at the build site (confirmed by block id).

- On the flat test stand the flood occasionally spends ~40s "searching for liquid" before the first

  natural water); it recovers. A real world has natural water.
