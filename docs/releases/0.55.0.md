# 0.55.0 — schematic placement core (buildBlocks) + aim-jitter telemetry

## What's new

- **py4j / MCP `buildBlocks(blocks)`** — the schematic placement CORE: place a batch of
  typed blocks (a list of `[x, y, z, name]`, world coords) bottom-up so each cell has
  support, in reach, capped per call. The cognitive agent parses a `.schem`/`.litematic`
  into this list and drives the build: `buildBlocks` → reposition (`gotoXYZ`) for
  `remaining` → `buildBlocks` again. Real survival placement; per-block hotbar equip.
  Foundation for schematic building (#8). MCP takes a JSON-array `blocks` string.
- **`getAimSamples(n)` + `AimSampler`** — per-tick yaw ring buffer to QUANTIFY aim jitter
  (the "прицел трясёт" shake). Pure read, no behavior change.

## Validated

- `diag_build`: a mixed stone/cobblestone structure placed correctly bottom-up. PASS.
- `aim_jitter_test`: `;punkPlayer` vs a strafing victim — the fighter tracks with only
  **0.7 Δyaw-reversals/s** (smooth), quantitatively confirming the v0.47/0.48 aim
  smoothing. PASS. `pvp_moving` regression PASS (sampler didn't touch combat).
- Regression: `worldedit_shapes_test` 3/3, `break_test` 4/4.
