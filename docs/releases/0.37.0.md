# 0.37.0

Release-ordering fix (same code as 0.36.0), and `targetCommitish` now points at the
active branch.

## Why 0.37.0

GitHub sorts releases by `created_at`, which is **immutable** once a release object
exists. A batch of releases (v0.21.1, v0.26, v0.27, v0.32–v0.36) had been pre-created
on 2026-04-03, so publishing onto those tags kept the April date and they sorted
below the July 0.28–0.31 releases — the newest work looked older. `overwrite` updates
content but can't reset `created_at`, so the only clean fix is to release on a tag
with no stale object: 0.37.0 is fresh, so it lands at the top with the correct date.

Also fixed the root: `build.gradle` now sets `targetCommitish = "1.21.11"` (the active
branch) instead of the stale `main`, so future releases anchor to real commits.
