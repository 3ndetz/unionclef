# 0.50.0

WorldEdit shape generators: `//hollow`, `//cyl`, `//sphere` (agent primitives, py4j + MCP).

## Shapes (#9.2)

On top of the existing `//set` / `//walls` fill core (real survival placement, bottom-up,
per-call cap, reposition on out-of-reach):

- `hollowSelection` (//hollow) — the 6-face shell (walls + floor + ceiling), interior open.
- `cylSelection` (//cyl) — the solid cylinder inscribed in the selection (circle in XZ).
- `sphereSelection` (//sphere) — the solid ellipsoid inscribed in the selection.

`select(x1,y1,z1,x2,y2,z2)` then call the op with a block name; if `remaining>0`, reposition
(gotoXYZ) and call again. Stand test `worldedit_shapes_test` 3/3 (each fills the expected
shape count, strictly between empty and the full box).
