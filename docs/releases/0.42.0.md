# 0.42.0

Bridging is now a real pathfinder move — the block-space search plans it as part of the
route (an agent primitive), not just a reactive stall.

## Place-as-a-move in the core search (#46)

Breaking has long been a first-class move in the block-space search (`tryPlanBreakThrough`).
Placing now is too — its exact mirror:

```
BlockNode.tryPlanPlaceThrough (toPlace)  →  PathFinder.pendingPlaces
  →  PathExecutor.tickPlacing            (mirror of  toBreak → breakQueue → tickBreaking)
```

A gap cell (body fits, no floor under it) is accepted with a plan to place its support;
the physics leg truncates at the gap edge (it can't simulate walking onto a floor that
isn't there yet), the executor paves the support, and the goto continuation re-searches
the now-bridged world. A bridge cell's *planned* floor counts as solid for the next cell,
so **one search plans a whole multi-cell bridge** instead of exhausting its node budget
into a CPU spin.

**Capability-aware and segmented**, the way real navigation needs it:

- Gated on `planPlaceMoves` — so with it off, parkour/walk routing (and every existing
  path) is completely unaffected.
- Per-cell `PlaceRules.canPlace` is honoured, so bridging routes around protected/claimed
  areas — a single path can break here, place there, walk elsewhere (just like per-cell
  `BreakRules` for breaking). This is the one capability-aware pathfinder.
- Only bridges *toward* the goal, so open terrain doesn't blow up the search.

**How to use it (agent primitive):** enable `setTungstenPlanPlaceMoves(true)` (the agent
decides when it may build), keep a block in the inventory, and `;goto` across the gap.

Tested: `core_bridge_test` — `;goto` across a 7-wide sky void with a block in hand plans
the bridge and crosses, leaving blocks in the gap that prove it (no CPU spin). `terrain_test`
course B (parkour, planPlaceMoves off) unaffected; break courses intact.

Also fixed a nasty stand bug: `slime_test` left `verboseDebugLogging` on, whose per-tick
physics dump floods the log and chokes the whole test stand.
