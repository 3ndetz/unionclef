# 0.49.0

Combat feel is now **live-tunable** — the aim-shake and bunny-hop are live-only symptoms the
test stand can't reproduce, so instead of guessing values and rebuilding, you can dial them
in-game with `;settings`.

## Tunable knobs (defaults = current behaviour, no change)

- `combatAimSmoothing` (0.5) — aim low-pass. If the aim still **shakes** on a live target,
  LOWER it (try 0.35 / 0.25). If it **lags behind** a strafing target, RAISE it (0.7).
- `combatVelSmoothing` (0.4) — enemy-velocity EMA for the lead. Lower = steadier lead.
- `combatBunnyHopMinMs` (280) / `combatBunnyHopRandMs` (320) — jump cadence. Lower = hops more.

Example in chat: `;settings combatAimSmoothing 0.3`
