# 0.26.0

A big one for the external-control side: the mod is now a proper **workplace for
a cognitive agent** — an agent (Claude over py4j or MCP) sees the game, moves,
fights, and builds through clean levers. Plus godbridge, WorldEdit-style fills,
claim/protection awareness, and far-route navigation. Everything below was
tested on the docker autotest stand (`deploy/runner/*`).

## Agent control surface

- **MCP server, hosted in the mod.** The mod runs a Model Context Protocol
  server over HTTP (`com.sun.net.httpserver`, no deps), bound to `0.0.0.0` — an
  agent drives the bot over the LAN at `http://<ip>:25350/mcp`, no py4j bridge
  or docker-exec. ~29 tools (perception / movement / combat / building /
  protection / menus), each with a description and JSON schema. Settings:
  `mcpEnabled` (default true), `mcpPort` (25350). See
  [docs/features/MCP_SERVER.md](../features/MCP_SERVER.md).
- **Perception in one call.** `getGameState()` returns self (hp/pos/armor/held/
  blocks), nearby players (name/pos/distance/hp/sprinting) and beds — the
  agent's battle view without screenshots.
- **Movement levers.** `gotoXYZ(x,y,z)` + `pathStatus()` (busy/pos/distance/
  arrived) navigate via tungsten; `gotoFar(x,y,z,horizon)` walks a far target in
  receding-horizon segments so the pathfinder never freezes on a huge goal;
  `stopPathing()` halts everything. Full lever catalog in
  [docs/features/AGENT_PY4J_LEVERS.md](../features/AGENT_PY4J_LEVERS.md).

## Building

- **Godbridge.** `bridgeForward(dir, n)` / `bridgeTo(x,y,z)` — continuous
  pave-ahead bridging at sprint speed, aim routed through the humanized mouse
  pipeline (never setYaw/setPitch — anti-cheat safe).
- **WorldEdit-style fills.** `select(...)` a region (shown as a box), then
  `fillSelection(block)` (//set) or `wallsSelection(block)` (//walls, hollow).
  Places real blocks (works in survival); the agent repositions for cells out
  of reach. `buildDefenseAround(x,y,z)` boxes a point (bed defense).
- **Placing primitive.** `placeBlockAt(x,y,z)` aims at a supporting face and
  places; `inventorySpace()` reports free slots + block counts for planning.

## Claim / protection awareness

- Tungsten now honours protected areas for **both** breaking and placing —
  symmetric with baritone's avoidance. `markProtectedArea(x,y,z,r)` locks a
  cube (claim) the bot won't mine or build in; `canBreakBlock` / `canPlaceBlock`
  predict the policy. Bridging and fills stop at claims. Settings: `allowPlace`,
  `placeDenyZones`.

## Combat

- **Multi-target / avoid-target.** `punkAny(allow, avoid)` hunts the nearest
  acceptable player (allow = candidates, empty = any; avoid = never hit) and
  re-targets automatically — you pick who to fight, the mod executes. `punk`,
  `punkAvoid`, `punkStop`, `punkStatus` round it out.
- **Bow ballistics.** `shootArrowAt(player)` / `solveArrowAim` compute the
  trajectory with target lead; `shieldBlock(ticks)` raises the shield.

## Visualization

- New toggles: `renderVisualization` (master), `renderPathMoves`,
  `renderBreakPlan`, `renderPlacePlan`, `renderCombat` — turn off parkour-move
  overlays while keeping combat/plan overlays, etc. Godbridge draws the cells
  it's about to place (green); selections show a yellow box.

## Notes

- Primary interface is now py4j (port 25333, tests) and MCP (25350, agents) —
  same levers, one source of truth. Chat commands (`;goto`, `;bridge`, `;punk`)
  still work.
- Known: far-route chunking and protection auto-detect live at the lever level;
  deeper in-core integration (tungsten as a full baritone drop-in, schematic
  building, resource-aware building) is in progress.
