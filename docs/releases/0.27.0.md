# 0.27.0

Navigation release: the cognitive-agent nav layer got much more robust. Tungsten
now drives real altoclef tasks, a long-standing bug that froze all navigation on
peaceful worlds is fixed, and the bot swims out of water instead of drowning.
Everything below was tested on the docker autotest stand (`deploy/runner/*`).

## Tungsten as a navigation drop-in

- **`setTungstenPathing(on)` / `pathingMode()`** (py4j + MCP): route altoclef's
  navigation through the tungsten physics pathfinder. With it on, `@goto`/`@get`/
  `@gamer` drive movement via tungsten. Tested: `@get log 3` on tungsten-primary —
  the bot walks to a tree and chops 3 logs; `@goto` reaches its target.

## Big bug fixes

- **Navigation was globally starved on peaceful worlds.** `MobDefenseChain` won
  the task-chain priority contest every single tick (a stale run-away task at
  priority 70, from a commented-out peaceful short-circuit), so the user task
  chain — which drives all `@goto`/`@get`/`@gamer` movement — never ticked and the
  bot just stood there. Restored the peaceful stand-down. This unblocked *both*
  tungsten and baritone navigation.
- **Input was nullified under altoclef tasks.** Baritone's InputOverrideHandler
  installed a zero-input movement handler while an altoclef task was active, which
  cancelled tungsten's key presses — the bot froze while the sim ran ahead (huge
  "drift"). It now yields input to tungsten while the tungsten executor is driving.

## Water

- **Tungsten swims out of water instead of drowning.** The block-space search
  routed water moves through the walk validator, which mishandled vertical/
  underwater moves and rejected valid swim-up nodes — the bot sank and drowned.
  Water cells are now swim-traversable directly, and surface cells within reach
  are accepted, so the pathfinder computes a real swim-out path. Tested: dropped
  into a pool, the bot swims up and out to its goal at full health.

## Building levers (recap, since 0.26.0 landed them)

`placeBlockAt`, `buildDefenseAround`, godbridge, claim/protection awareness
