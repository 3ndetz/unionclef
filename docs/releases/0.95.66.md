# Jump when there is no ground

A run from `repro-lava-stuck-cell` on 0.95.65 burned to death 0.9 blocks from the shore of the
portal-site pool. The escape route was two cells long, the second one block up. The walker
presses jump only from the ground, and a body floating in lava is never on the ground, so it
walked into the shore face at zero speed until it died ("wlk i1/2 d0.9 wp(-250,26,1105) g0 j0").

The walker now holds jump while its feet are in a liquid and the next waypoint is above them --
baritone's rule (`Movement.java:125-127`). Lever: `walkerJumpsInLiquid`.

Measured:

- new course `escape_lava_deep_kit` (a two-deep lava pit, the bot floating, cobblestone in the
  pack; resistance on so both arms live long enough to compare), same jar, lever pinned:
  off 43.7 / 27.9 / 24.0 s to get out, on 8.7 / 15.7 / 6.0 s. It is a gate now: out within 20 s.
- from `repro-lava-stuck-cell`, 10 minutes each: two runs, 0 deaths, both reached the nether
  (one took its first ender pearl at 5.5 minutes). The same checkpoint on 0.95.65: one death in
  two runs.
- craft 29/29 gates and `nav_flat`, `nav_staircase`, `nav_water`, `nav_water_pillar`, `nav_bridge`
  PASS at 29-30 FPS.
