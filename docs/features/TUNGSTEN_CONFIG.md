# Tungsten — конфигурация (`config/tungsten.json`)

Меняется на лету: `;settings <имя> <значение>` (bool/числа), либо правкой JSON
и перезаходом. `;settings` без аргументов печатает текущие значения.
ВАЖНО: сохранённый файл переопределяет новые дефолты мода — после обновления
сверяй ключевые флаги (или удали файл, он пересоздастся с дефолтами).

## Ломание блоков

| Поле | Дефолт | Что делает |
|---|---|---|
| `allowBreak` | `true` | Разрешить планировщику пробивать ломаемые стены (`;goto` сквозь препятствия). `false` — только обход. |
| `breakCostMultiplier` | `1.0` | Множитель стоимости ломания в планировщике. Больше — сильнее предпочитает обходы. |
| `breakDenyBlocks` | `[]` | Id блоков, которые НЕЛЬЗЯ ломать никогда (например `"minecraft:diamond_block"`). Блоки с block entity (сундуки, спавнеры, печи) запрещены всегда. |
| `breakDenyZones` | `[]` | Зоны запрета ломания: массивы `[x1,y1,z1,x2,y2,z2]` (включительно, порядок углов любой). |
| `driftThreshold` | `0.8` | Порог расхождения реплея с симуляцией (блоки) до аборта пути. На маршрутах с проломами (протискивание в 1-блочную дыру) поднимай до `1.5`. |
| `driftCorrectionEnabled` | `false` | `true` — телепортировать игрока в позицию симуляции при дрифте (чит-стиль); `false` — остановить и пересчитать. |

Плюс защиты altoclef: его break-avoiders (защита кроватей, protected-зоны
тасков) автоматически действуют и на tungsten через `canBreakHook` — отдельная
настройка не нужна.

## Комбат

| Поле | Дефолт | Что делает |
|---|---|---|
| `combatTriggerBotEnabled` | `true` | Автоудар при выполнении гейта (рич/LOS/угол/кулдаун). |
| `combatRotatesEnabled` | `true` | Автоприцел на цель (WindMouse). |
| `combatMovementsEnabled` | `true` | Ноги боя: сближение, дожим последних полблока, спринт. `false` = стоит столбом и его кайтят. |
| `combatSaverEnabled` | `true` | Система выживания: тормоз у края, отступ при опасном отбросе. |
| `combatExecutorEnabled` | `false` | Экспериментальный планировщик атакующих окон (пока только визуализация). |
| `combatWindMouseGravity` | `2.0` | Скорость сведения прицела. Больше — быстрее, меньше — человечнее. |
| `combatWindMouseWind` | `0.8` | Случайное дрожание прицела. |
| `combatWindMouseMaxStep` | `4.0` | Макс. градусов поворота за кадр. |
| `combatWindMouseFlickScale` | `3.0` | Ускорение флика на большие углы. |
| `combatWindMouseWindDist` / `DoneThreshold` | `15.0` / `0.5` | Затухание дрожания у цели / порог снапа. |

## Преследование (follow)

| Поле | Дефолт | Что делает |
|---|---|---|
| `enableLeap` | `false` | Спринт-прыжки к цели вблизи без A* (камеру ведёт комбат/altoclef). |
| `enableTrailing` | `false` | След-режим: идти по следу цели при отрыве >20 блоков. |
| `followBlockPathFinderEnabled` | `false` | BFS-walker для мгновенного старта, пока A* думает (экспериментально). |
| `followJumpingEnabled` | `true` | Разрешить прыжки при преследовании. |

Гистерезис пере-планов зашит в код: не чаще раза в 2с и только при смещении
цели больше max(3 блока, 25% остаточной дистанции).

## Пути и исполнение

| Поле | Дефолт | Что делает |
|---|---|---|
| `searchTimeoutMs` | `15000` | Бюджет physics-поиска (мс). Follow сам ставит 120–3000 по дистанции; `;goto` возвращает 15000. |
| `enableParallelStreaming` | `true` | Параллельная генерация нод A*. Выключи при редких ConcurrentModificationException. |
| `airStrafeMultiplier` | `1.0` | Воздушный контроль симуляции. `1.0` = ваниль-точность; `3.0` = агрессивные прыжки старого tungsten. |
| `enableNativeRotation` | `true` | Повороты через пиксельную мышиную математику (неотличимо от мыши для античитов). |
| `enablePitchChange` / `pitchLookAheadNodes` | `true` / `5` | Косметика: смотреть на ноды пути впереди. |
| `verboseDebugLogging` | `false` | Подробный лог (эмиссии путей, гейт триггера, тайминги) — для дебага. |
| `debugTime` | `false` | Тайминги пасфайндера в stdout. |

## Совместимость (ViaVersion-сервера)

| Поле | Дефолт | Что делает |
|---|---|---|
| `avoidStuckFence` | `true` | Не строить пути через заборы/стенки с невидимыми клиенту коллизиями соединений. |
| `avoidStuckAnvil` | `true` | Не подходить к наковальням сбоку (ротация коллизии может отличаться). |
| `predictDamageFromBlocks` | `true` | Учитывать замедление от урона (кактус/огонь/куст) в симуляции. |

## Py4j prediction API (внешнее управление)

- `canBreakBlock(x, y, z)` → bool — разрешит ли политика ломания этот блок
  (учитывает конфиг, зоны, block entities и защиты altoclef).
- `canReach(x, y, z, withBreaking)` → map: `found`, `pathSize`, `breaks`
  (сколько блоков плана придётся сломать), `endDistance` (насколько близко к
  цели дошёл черновой маршрут; малое значение = реально достижимо),
  `busy=true` если пасфайндер занят. Эвристика «дойдём ли: с ломанием / без».
