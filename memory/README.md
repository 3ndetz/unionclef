⛔ **Костяк — это `PERSONA.md` и `persona_card.md`, и они здесь не лежат.** Память меняется,
характер нет. Смешаешь — получишь mineswarm, где `state.md` дорос до 117 КБ при костяке 18 КБ
и одна сессия стоила четыре доллара.

Перед каждой сессией этот файл обрезается кодом, а не совестью: заголовок, свежие срезы,
долговечные разделы. Старое уезжает в архив, который в контекст не грузится никогда.

---

⛔ **Один оригинал на весь комплекс.** Этот файл лежит здесь ОДИН раз и подкладывается
каждой единице в её рабочее место на чтение — `/work/memory/README.md`. Раньше он был
скопирован восьми единицам: восемь одинаковых файлов, один и тот же md5, и восемь мест,
где правка расходится с остальными.

Копией это стало не по лени. В песочнице единица видит ТОЛЬКО свой каталог, и ссылка на
`docs/` оттуда не дотягивается. Правильный ответ на это — общий **ДОСТУП**, а не копия:
файл подкладывается монтированием, единый для всех и правится в одном месте.
